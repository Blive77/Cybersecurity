## PenTest

The [PenTest section](PenTest/README.md) is a practical pentesting playbook organized by assessment phase. It covers methodology, reconnaissance, enumeration, services, web attacks, exploitation, post-exploitation, Active Directory, password attacks, tooling, cloud, network attacks, and reference material.

Start with the [Engagement Workflow quick start](PenTest/00%20-%20Methodology/Engagement%20Workflow%20(Quick%20Start).md), then browse the [PenTest notes](PenTest/).

These notes are intended for authorized security assessments, training labs, and CTF environments.
